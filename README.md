# ToolHub

A 100% client-side catalog of browser-based utilities. No backend, no
accounts, no tracking — every tool runs entirely in your browser.

```bash
npm install
npm run build   # generates the static site into public/
npm run serve   # → http://localhost:4173
npm test        # unit tests for every tool's logic
```
