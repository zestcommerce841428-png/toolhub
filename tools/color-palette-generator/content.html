How each scheme is built

Every palette is generated by rotating your base color's hue around the color wheel in HSL space, not picked from a canned lookup table: complementary is +180°, analogous is ±30°, triadic is +120°/+240° (evenly spaced), split-complementary is +150°/+210° (softer than a direct complement), and monochromatic keeps the hue fixed while varying lightness for a set of tints and shades.
