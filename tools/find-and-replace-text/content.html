Using regular expressions

With "Use regular expression" enabled, Find is a real JavaScript regex pattern (no need to wrap it in slashes), and Replace with can reference capture groups — $1, $2, and so on — from parentheses in the pattern. For example, finding (\d+)-(\d+)-(\d+) and replacing with $2/$3/$1 reformats a YYYY-MM-DD date to MM/DD/YYYY.
