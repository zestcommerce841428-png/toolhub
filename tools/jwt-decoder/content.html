What this decodes

A JWT is three base64url-encoded parts separated by dots: a header (algorithm + token type), a payload (claims), and a signature. The header and payload are never encrypted — anyone can decode them without a secret, which this tool does automatically. The signature is what actually proves the token wasn't tampered with, which is what the optional verification step checks for HMAC-signed tokens.
