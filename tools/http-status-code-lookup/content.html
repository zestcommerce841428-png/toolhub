The five status code classes

The first digit of every HTTP status code tells you its class before you even read the rest: 1xx informational, 2xx success, 3xx redirection, 4xx client error (the request was wrong), 5xx server error (the server failed to fulfill a valid request). This is a complete reference, including the less-common WebDAV and rate-limiting codes, not just the handful of codes any given API happens to use.
