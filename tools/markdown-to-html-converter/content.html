What's supported

Headings, paragraphs, bold, italic, inline code, fenced code blocks, links, images, blockquotes, ordered/unordered lists, horizontal rules, and hard line breaks (end a line with two spaces). Not supported: tables, nested lists/blockquotes, footnotes, and reference-style links — this covers the common subset most everyday Markdown actually uses, not the full CommonMark specification.

Safe by construction

Any raw HTML you paste — a stray <script> tag, for instance — is escaped to inert text rather than rendered live, and link/image URLs reject the javascript: scheme. The preview pane is exactly what the generated HTML would show if you used it on a real page.
